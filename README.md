# 🎤 Speaker Bot

**Deutsch + Deitsch + Englisch - mit automatischem Stimmen-Wechsel!**

Der Speaker Bot hört dir zu und spricht alles nach, was du sagst.
Mit Jonas (Deutsch) und Ryan (Englisch)!

**Live ausprobieren:** https://DEIN-NAME.github.io/speaker-bot/

---

## ✨ Was kann er?

- 🎤 **Zuhören & Nachsprechen** - Sag was und er sagt es nach!
- 🇦🇹🇬🇧 **Auto Stimmen-Wechsel** - Deutsch = Jonas, Englisch = Ryan
- 📊 **Graf** - Zeigt live, wie laut du bist!
- 📜 **Verlauf** - Alles was er gehört hat, mit Uhrzeit!
- 🤫 **Piep-Filter** - Schimpfwörter werden zu PIEP!
- 🎙️ **Mikro fragt nur 1x** - Kein nerviges Nachfragen mehr!
- 🤫 **Bleibt leise** - Wenn er nix versteht, sagt er gar nix!

## 🚀 So benutzt du ihn

1. Link öffnen: https://DEIN-NAME.github.io/speaker-bot/
2. Auf **▶️ START** klicken
3. Mikro erlauben - auf **Zulassen** klicken
4. Einfach reden!
5. Auf **⏹️ STOP** klicken zum Aufhören

## 🎛️ Einstellungen

- **🌍 Sprache:** Deutsch / Deitsch / Englisch / Mix (Alle zusammen)
- **😎 Streamer:** Tief & cool
